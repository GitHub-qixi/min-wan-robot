# 桌面陪伴机器人：可行性、竞品与 MVP

> 会话纪要整理 · 产品方向备忘

## 1. 产品想法

做一个小型桌面实体机器人，主打语音识别与全天在线陪伴聊天，并商业化。

核心架构设想：

- **微型主机**：持续交流服务，存个人会话/记忆等数据，接入大模型
- **机器人本体**：转发 + 动作/表情交互壳，不做复杂工具操作
- **能力边界**：类似 OpenClaw 的交流与记忆，但**不具备**实际操作工具；主打陪伴
- **数据**：可存本地，用户买走一台微型服务器

**结论：可行。** 比完整具身机器人更容易落地。更准定位是「本地隐私陪伴设备 / 桌面情感伴侣」，而非「具身机器人平台」。

## 2. 为什么可行

1. 复杂度可控：ASR → 对话/记忆 → TTS → 表情/简单动作即可
2. 架构合理：脑在主机，壳在机器人，隐私卖点清晰
3. 用户价值好懂：「会记得你的桌面陪伴机器」

## 3. 主要风险

| 风险 | 说明 |
|------|------|
| 陪伴粘性 | 几天新鲜后是否还愿意长期开机 |
| 语音体验 | 延迟、打断、噪音、方言、误唤醒 |
| 记忆质量 | 要记得偏好与近况，并能自然用出来 |
| 成本与毛利 | 主机 + 麦阵 + 舵机/屏幕 + 售后 |
| 模型成本 | 云端有 API 费；全本地要更强主机 |
| 替代品 | 手机 App、智能音箱：「为什么非买硬件？」 |

## 4. 竞品概览

有竞品，但**几乎没有完全同构**（本地微型服务器 + 长期记忆 + 实体只做壳）。

### 直接竞品（桌面陪伴硬件）

| 产品 | 定位 | 差异 |
|------|------|------|
| EMO（Living.ai） | 桌面 AI 宠，能聊、认人 | 偏云端，非本地陪伴主机 |
| Eilik（Energize Lab） | 表情+触摸解压桌宠 | 基础款不能认真聊天 |
| Loona / Deskmate（可以科技） | 机器宠物 / iPhone 桌面助理 | Deskmate 偏办公，非纯陪伴记忆 |
| ElliQ | 老人陪伴+健康 | 订阅制、强云端、银发向 |
| 芙崽 / Ropet / AIBI 等 | 潮玩、养成、口袋宠 | 记忆与本地服务器弱 |

### 间接竞品

- 智能音箱：小度、天猫精灵、小爱（便宜常在线，人格/记忆浅）
- App 陪伴：星野、Glow、Replika 等（无实体，多云端）
- 本地/开源对话：OpenClaw 类、屏幕桌宠（有脑少实体）

### 差异化空白

1. 硬件 SKU = 微型服务器（本地存会话/记忆）
2. 机器人 = 转发 + 动作/表情壳
3. 能力 = 陪伴对话 + 记忆，不做工具操作
4. 卖点 = 全天在线、数据在家、人格连续

成败不在「像不像机器人」，而在语音体验、记忆是否让人感到被理解、是否愿意长期开机。

## 5. 最佳 MVP 实现方式

**原则：先不验证机器人，先验证「本地记忆 + 全天语音陪伴」是否有人天天用。**

### 三层架构

```
[交互层]  手机 App / 网页 / USB麦+音箱
    ↕  WebSocket / 局域网
[大脑层]  微型主机（N100 等）
    - ASR / 对话+记忆 / TTS / 本地库
    ↕  API（可选）
[模型层]  云端大模型（先） / 本地小模型（后）
```

机器人是第三阶段把交互层换成实体；大脑协议不变。

### 阶段

| 阶段 | 做什么 | 成功标准 |
|------|--------|----------|
| Phase 0（1–2 周） | 文字/可选语音 + 人格 + 长期记忆 + 每日问候 | 连续用 7 天+，感到「它记得我」 |
| Phase 1（2–4 周） | 常开主机 + 语音全天在线（云端 ASR/LLM/TTS） | 日活语音稳定；愿意一直插着；有付费意向 |
| Phase 2 | 实体壳：麦阵+喇叭+表情+简单舵机，只转发 | 大脑不变，只加在场感 |

### 技术最小栈方向

- 主机服务：api / asr / chat / memory / tts / store / realtime
- 记忆 MVP：摘要 + 用户事实抽取 + Top-K 注入 prompt；SQLite（+ 轻量向量）；可导出/清除
- 先砍掉：工具调用、自研麦阵、本地 70B、底盘、复杂表情工程

### 可卖的第一版商品

> 「家庭陪伴主机」：插电即用，本地存记忆，接大模型，手机/音箱聊天；预留机器人接口。

**一句话：最好的 MVP = 常开小主机 + 本地记忆服务 + 云端 LLM/ASR/TTS + 手机语音入口；机器人等粘性跑通再上。**

## 6. 商业化初步判断

更像 **消费电子 + 订阅**，而非机器人平台。

- 硬件售卖（主机 / 主机+机器人）
- 云端模型 / 高级记忆 / 音色订阅
- 可选：角色包、声音包、外观

先测假设：用户是否愿意为「本地记忆 + 全天陪伴语音」付硬件钱，而不是继续用免费聊天 App。
